# Créditos de imágenes del catálogo de demostración

Las fotografías precargadas se muestran mediante URLs externas y se usan únicamente como material visual de demostración académica. El administrador puede reemplazarlas subiendo sus propias imágenes desde AutoRent.

Modelos precargados:
- Toyota Corolla 2024: AutoScout24 / Sarasota Toyota / Marietta Toyota.
- Chevrolet Onix 2023: UsadosBR / deRuedas / Catarina Carros.
- Kia Sportage 2024: DubiCars / CarBase / Airport Kia of Naples.
- Hyundai Tucson 2023: Daum/Kakao / Autoboom / The Auto Channel.
- Ford Ranger 2024: Ford / Pickup Truck Talk / MotorTrend.
- Toyota Hilux 2023: Autocosmos News / AutoBusiness / Regiovanio Veículos.
- BMW X3 2024: Alba Cars / All Cars Online / BMW Używane.
- Mercedes-Benz GLC 2024: Autozone / WhichCar.

Nota: al ser URLs externas, se necesita conexión a Internet para visualizar las fotografías precargadas. Las imágenes que suba el administrador se almacenan en la aplicación y no dependen de estas URLs.
